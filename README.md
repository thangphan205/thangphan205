## 🚀 Featured Projects

### [netconsole](https://github.com/thangphan205/netconsole) ⭐ 27
A full-stack web application for managing network switch interfaces. Configure interfaces, view ARP tables, MAC addresses, and IP configurations all from a modern web interface.
- **Tech Stack**: TypeScript, FastAPI
- **Features**: Switch interface management, ARP/MAC address viewing, IP address configuration

### [tacacs-ng-ui](https://github.com/thangphan205/tacacs-ng-ui) ⭐ 12
Modern Web UI for configuring and managing tac_plus-ng with advanced features for AAA administration.
- **Tech Stack**: TypeScript
- **Features**: AAA log auditing, trends dashboards, SIEM integration, user/profile management

### [network-thuc-chien](https://github.com/thangphan205/network-thuc-chien) ⭐ 6
Documentation and resources from my YouTube channel Network Thực Chiến
- **Content**: Networking tutorials, guides, and practical examples in Vietnamese

### [containerlab-demo](https://github.com/thangphan205/containerlab-demo) ⭐ 1
Step-by-step demonstrations of network scenarios using Containerlab
- **Tech Stack**: Shell, Containerlab
- **Purpose**: Network topology simulations and testing
